Path: `MiniOS-Java/javafx/src/main/java/MiniOSFX.java`. Source revision: `dba2d32`.

This is the current JavaFX entry point. It creates the window and reads module definitions from Modules.all(). Buttons and typed commands open the same Editor cards. Each card collects raw text/options, and a JavaFX Task invokes the existing module runner on one background worker. Task completion handlers display real results on the JavaFX application thread. The frog interface is deterministic command routing, not an AI or a remote service. advancedCpu is session-only state controlled by Ctrl+Shift+M (Command+Shift+M on macOS).

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
