[Guide index](README.md) · [Exact source snapshot](https://github.com/ceias/minions/blob/dba2d321e276383939b0bf661659738741bdd343/MiniOS-Java/Modules.java)

Path: `MiniOS-Java/Modules.java`. Source revision: `dba2d32`.

This file is the catalog shared by both GUIs. It describes inputs rather than drawing a GUI or implementing scheduling itself. A Module has a name, instructions, fields, three samples and a Runner callback. The same definition therefore builds both Swing and JavaFX forms. The list ordering matters: JavaFX's CPU/page button groups and command aliases assume the current order.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
