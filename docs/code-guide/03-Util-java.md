Path: `MiniOS-Java/Util.java`. Source revision: `dba2d32`.

Shared parsing and formatting utilities used by the engines and both interfaces. They throw IllegalArgumentException for validation errors; the interface catches it and displays a message. Numeric input is individually bounded to ±1,000,000,000; this is a numeric-value bound, not a fixed limit on the number of data items. Static methods let callers write Util.one(...) without constructing a Util object.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
