Path: `MiniOS-Java/Memory.java`. Source revision: `dba2d32`.

This file contains three independent memory simulations. Paging uses fixed-size pages mapped to frames. Segmentation uses a base and exclusive offset limit. Fragmentation allocates each supplied fixed block to at most one process using First/Best/Worst Fit. It does not split blocks or simulate variable-partition compaction.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
