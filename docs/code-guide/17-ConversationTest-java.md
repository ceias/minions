JUnit tests launch the real JavaFX scene with Monocle's headless software renderer. GUI access is scheduled on the JavaFX thread, while JUnit waits outside it. There are five tests: shortcut/state behavior, audit engine regressions, all-module result paths, command/draft preservation, and validation recovery. The shortcut test invokes the registered accelerator action; it does not emulate a physical Windows keyboard. File dialogs/clipboard and native Windows appearance are not exhaustively verified here.
