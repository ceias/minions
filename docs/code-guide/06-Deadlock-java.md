Path: `MiniOS-Java/Deadlock.java`. Source revision: `dba2d32`.

This detects existing deadlock from current Allocation, outstanding Request and Available vectors. It differs from Banker, which considers future declared maximum demand. Processes holding no resources are marked finished for deadlock detection. Recovery is a greedy suggestion to terminate large resource holders, not a proof of the minimum number of victims. Unlike Banker's corrected Work totals, this implementation still uses int resource-vector helpers; do not describe its arithmetic as arbitrary precision.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
