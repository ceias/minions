Path: `MiniOS-Java/MiniOS.java`. Source revision: `dba2d32`.

This is the original Swing interface, retained alongside JavaFX. The root MiniOS.jar launches this class, while the Maven JavaFX launcher uses MiniOSFX. Swing calls GUI callbacks on its Event Dispatch Thread. execute() in this version calls the engine synchronously; the JavaFX version instead uses a background Task. ModulePanel is also instantiated by the headless reference/rubric tests, so it is not unused merely because you normally run JavaFX.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
