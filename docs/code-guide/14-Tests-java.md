A standalone reference test runner. check compares expected and actual values and records pass/fail. The tests cover CPU timing/Gantt examples, replacement counts and final states, safety/deadlock cases, disk totals, text fixtures and Swing module panels. It terminates with exit0 only if all checks pass. It must run from MiniOS-Java or receive a fixture path argument. Compatibility fixtures are not a proof of universal correctness; corrected disk fixtures are documented separately.
