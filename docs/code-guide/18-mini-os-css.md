JavaFX CSS styles nodes by classes added from MiniOSFX. These are JavaFX -fx-* properties, not ordinary browser CSS. Styling does not calculate algorithms. Most rules are intentionally on one physical line, so a single numbered row may contain several property assignments.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
