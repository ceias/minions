Path: `MiniOS-Java/Cpu.java`. Source revision: `dba2d32`.

This is a tick-based, single-CPU scheduler. Proc is immutable input; Result stores the execution timeline; Metrics contains calculated statistics. The UI sends parsed processes to report(), which calls sim(), calculates metrics(), and formats the report. Lower priority numbers win. MLQ uses fixed queue assignments; MLFQ changes levels after full time slices. This is a simulation, not code that schedules real Windows processes.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
