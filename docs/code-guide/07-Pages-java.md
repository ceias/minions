# Pages.java — line-by-line explanation

[Guide index](README.md) · [Exact source snapshot](https://github.com/ceias/minions/blob/dba2d321e276383939b0bf661659738741bdd343/MiniOS-Java/Pages.java)

Path: `MiniOS-Java/Pages.java`. Source revision: `dba2d32`.

A Ref contains a page name plus whether the access writes it. The simulator stores each page in a fixed frame and records a complete Step snapshot after every reference. R is the reference bit, M is the modified bit, ld is load time, lu is last-use time, and cnt is the NFU counter. Empty frames are filled before choosing a victim. FIFO/LRU/Optimal and six additional policies share the same input/output path. A page named 0w is interpreted as a write to page 0; names ending in w/W follow this convention.

Each row preserves one physical source line. Dense lines can contain several statements. Blank lines and closing delimiters are included so numbering matches your editor.
